# VL.Devices.LS2Lidar (WIP)

A plugin for [vvvv](https://vvvv.org) that provides support for SDKELI LS2027/LS1207DE LIDAR devices.

Tested with `LS2-2027D/H03`.

![splash](assets/splash.png)

⚠️ **This project is currently in active development**

### Packages

* `LS2Lidar` - common api for SDKELI LS2 Lidar devices.
* `VL.Devices.LS2Lidar` - vvvv plugin for SDKELI LS2027/LS1207DE LIDAR devices.
